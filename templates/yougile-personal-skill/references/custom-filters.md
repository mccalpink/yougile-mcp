# Custom Filters — Именованные фильтры пользователя

Система именованных фильтров позволяет сохранить часто используемые выборки
и активировать их по хук-фразе без повторного описания параметров.

---

## Что такое filters.md

Файл `~/.agents/skills/yougile-personal/filters.md` (или `$YOUGILE_USER_MEMORY_DIR/filters.md`).
Содержит именованные фильтры — tool chain'ы с хук-фразами и параметрами.

Агент читает этот файл при активации скилла (шаг 2 алгоритма).
Когда пользователь произносит хук-фразу — агент выполняет соответствующий tool chain
без переспрашивания.

---

## Алгоритм предложения сохранения

**Триггер:** пользователь 2+ раза в течение сессии или в разных сессиях запрашивает
одинаковую нестандартную выборку (те же параметры, тот же workspace, те же поля).

**Действие агента:**
«Вы уже второй раз просите эту выборку. Сохранить как именованный фильтр?
Тогда в следующий раз достаточно сказать "горящие в main".»

Если пользователь соглашается → создай запись в `filters.md` по шаблону ниже.
Шаблон файла: `templates/filters.template.md`.

---

## Формат записи в filters.md

```markdown
## Фильтр: <название>

- **Хук-фразы:** "<фраза1>", "<фраза2>", "<фраза3>"
- **Workspace:** <slug>
- **Что делает:** <описание одной строкой>
- **Tool chain:**
  - `<tool_name>(<params>)`
  - verbosity: <уровень>, include: [<список>]
  - Клиентский фильтр: <условие если есть>
- **Заметки:** <особенности, edge cases>
```

---

## Как читать filters.md при активации

1. Прочитай файл при старте сессии (шаг 2 алгоритма)
2. Построй map: хук-фраза → tool chain
3. При получении запроса от пользователя — сравни с хук-фразами (fuzzy match)
4. Если матч найден → выполни tool chain напрямую
5. Если матч неоднозначен → спроси: «Вы имеете в виду фильтр "горящие in main" или "срочные в team"?»

---

## Пример активации

Пользователь: «Покажи горящие»

Агент читает filters.md, находит:
```
## Фильтр: горящие задачи
- Хук-фразы: "горящие", "что горит", "overdue", "горит"
- Workspace: main
```

→ Выполняет сохранённый tool chain без переспрашивания параметров.

---

## Обновление filters.md

Агент **не изменяет** filters.md автоматически. Только предлагает пользователю.
Сохранение — явное действие после подтверждения.

При сохранении:
1. Прочитай текущий filters.md
2. Добавь новую запись в конец
3. Покажи что добавлено, попроси подтвердить перед записью
